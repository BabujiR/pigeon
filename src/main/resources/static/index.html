      Why alignment matters

      SPF and DKIM can both pass and DMARC can still fail. DMARC asks whether a passing check belongs to the same organization as the visible From address. Without custom MAIL FROM, SPF passes for amazonses.com, which is not you. Without Easy DKIM, the signature is SES's, not yours. Either one aligned is enough; production setups have both.

      Numbers to know
      
      
      
        
      SES bounce rateReview ≥ 5%, pause ≥ 10%
      
        
      SES complaint rateReview ≥ 0.1%, pause ≥ 0.5%
      
        
      Gmail/Yahoo spam rateStay under 0.1%, never reach 0.3%
      
        
      Bulk sender threshold5,000+ msgs/day to Gmail
      
        
      Bulk requirementSPF + DKIM, DMARC record, alignment, one-click unsubscribe
      
        
      Sandbox limitsVerified recipients only, 200/day, 1/sec
      
        
      SMTP 5xx vs 4xx5xx permanent (hard), 4xx temporary (soft)
      
        
      DKIM key2048-bit, rotate on a schedule
      
      
      
      
      Check AWS and Google docs before quoting limits in a meeting; they change.
      
    
      
    
      
      
      Risks a lead raises early
      
      
        
        
      • Sending enrollment and marketing from one domain and pool, so one bad list hurts every email.
        • 
        
      • No idempotency key, so a retry storm sends members duplicates.
        • 
        
      • Event processing that silently drops SNS messages, so suppression drifts.
        • 
        
      • Cutting over from the old platform without warming dedicated IPs.
        • 
        
      • DMARC jumping straight to p=reject before reports show every sender is aligned.
        • 
        
      • PII in logs and in S3 template payloads without encryption and retention rules.
        • 
        
      • Nobody owns the DNS change process, so records drift.
